### 01 · School ERP & Management System
**Full-Stack Desktop Application · Built for a live client, in production today**

A full-featured School ERP combining a React frontend, Electron desktop shell, Node.js/Express backend, and MongoDB Atlas — handling real fee collection, real students, and real data integrity requirements.

**Modules:** Student Management · Teacher Management · Fee Collection · Transport · Academic Year Management · Student Promotion · Transfer Certificates · Notices · Auth & RBAC

**Engineering highlights**
- JWT authentication with role-based access control
- Optimized MongoDB schemas and indexing
- Automated incremental/monthly backups via `mongodump`
- SHA-256 integrity verification on every backup
- Google Drive sync using `rclone`
- Automated email alerts & manual disaster-recovery workflow
- Packaged and deployed as a native Windows desktop app

`React` `Electron` `Node.js` `Express` `MongoDB Atlas` `JWT` `rclone` `macOS launchd`

### 03 · Zeronet
**Offline LAN Chat & File Sharing — zero internet required**

A peer-to-peer communication platform built from scratch for devices on the same Wi-Fi or hotspot. No servers, no internet, no dependency on anything outside the room.

```
Device A → mDNS/Bonjour Discovery → Socket.IO Signaling → WebRTC → P2P Channel → Chat + File Transfer
```

**Engineering highlights**
- Automatic device discovery using mDNS / Bonjour
- Real-time LAN communication over WebRTC P2P connections
- Direct device-to-device file transfer, 64 KB chunked with metadata-based reassembly
- React 18 + Vite frontend with Tailwind CSS and Framer Motion animations

`React` `Node.js` `Express` `Socket.IO` `WebRTC` `Vite` `Tailwind CSS` `Framer Motion`
